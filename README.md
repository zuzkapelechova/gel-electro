# GelElectro
Python software for gel-electrophoresis image processing:
- Preprocessing & artifact detection
- Band size & concentration analysis
- Reporting results in tables and plots

## Features
- Normalize brightness and contrast of gel images
- Straighten gel lanes
- Detect artifacts (smiling/frowning, streaking)
- Estimate fragment sizes using ladder standard curves
- Estimate DNA/RNA concentrations
- Generate summary reports for samples
